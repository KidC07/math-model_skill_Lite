# 每个人都能计算和写 LaTeX

论文统一用 LaTeX。每个人都能编辑源文件、编译和看 PDF。以下面向 Windows；已有可用环境直接看第 2 页，不重装。

## 需要装什么

1. VS Code：编辑代码和 .tex。扩展装 Microsoft 的 Python、James Yu 的 LaTeX Workshop。下载：code.visualstudio.com

2. Python 3.13：运行计算与绘图。已有可用的 3.12 可继续使用。新装勾选 Add python.exe to PATH。下载：python.org/downloads/windows/

3. Python 基础库：NumPy、Pandas、SciPy 计算；Matplotlib + Seaborn 绘图；openpyxl 读写 Excel；PyMuPDF 处理 PDF。清单已放在 requirements.txt。

4. TinyTeX：提供 XeLaTeX 编译器，把 .tex 变成 PDF，不需要安装 R。到 yihui.org/tinytex/ 保存并运行官方 Windows 安装脚本。已有能编译中文的 TeX 安装可继续用。

## 新电脑：装好后运行三行

完成上面的安装后，关闭并重开 VS Code，用它打开收到的完整文件夹，新建终端，逐行运行：

```text
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
tlmgr install ctex amsmath fandol
```

前两行准备 Python；第三行补齐中文、公式与通用中文字体。只在新电脑或确认缺项时执行；已有环境不要重复创建。若找不到 tlmgr，先重开终端并确认 TinyTeX 已安装。

## 两套工具各管什么

Python 负责算数和出图；XeLaTeX 负责论文编译；VS Code 负责编辑与预览。Skill 是给 AI 的工作说明，不附带这些软件。论文不需要 Word/WPS 或 python-docx。

# 检查一次，然后开始写

用 VS Code 打开整个文件夹，保留隐藏的 .agents 和 .vscode。包内已配好 XeLaTeX 编译与 PDF 预览。

## 1. 选 Python

按 Ctrl+Shift+P，输入 Python: Select Interpreter。新电脑选本文件夹的 .venv；已有环境选平时可用的 Python。随后关闭旧终端，新建终端。

```text
python -c "import sys; print(sys.executable)"
```

路径应与刚才选择的一致。若不一致，使用解释器完整路径；新电脑可把 python 换成 .\.venv\Scripts\python.exe。

## 2. 检查计算、绘图和 LaTeX

```text
python 快速检查.py
```

默认会实际编译中文、公式与交叉引用。看到“全部通过”，再打开提示的 PNG 和 LaTeX PDF 检查显示。失败时把报错和 Python 路径交给 AI；先查原因，不急着重装。

## 3. 编辑、编译、预览

打开论文主文件 main.tex，按 Ctrl+Alt+B 编译，按 Ctrl+Alt+V 看 PDF；修改后再次编译即可。默认 XeLaTeX 连续编译两遍，更新交叉引用；不需另外安装 Perl。

新赛题另建文件夹时，把本包的 .vscode 复制过去；已有配置让 AI 合并。首次使用该电脑时，在 VS Code 终端运行 xelatex --version 确认能找到编译器；找不到时先重启 VS Code。

## 4. 交给 AI，保留完整源文件

发送：“读取 .agents/skills/mathorcup-modeling/SKILL.md，使用本包处理我的任务。”再提供题目、数据或论文。论文交接保留 .tex、用到的 .bib、图表素材及编译后的 PDF，不只发一份 PDF。
