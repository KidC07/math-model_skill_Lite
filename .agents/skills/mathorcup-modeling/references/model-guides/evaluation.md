# 多指标评价

用于综合评分、排序或相对效率分析。先定义对象、指标、方向、单位、来源和决策用途，避免重复计量同一概念。评价模型不自动证明因果关系或行动最优性。

## 基线与候选

先建立能解释的权重与汇总对照；等权同样是一种选择，不能冒充无偏好。若题意已规定权重或规则，优先遵从。AHP 用于有依据的判断矩阵；熵权描述数据离散程度，不能替代现实重要性。

TOPSIS 适用于所选标准化和距离有合理含义的多指标比较；语言等级可考虑模糊评价；投入产出效率可考虑 DEA；目标序列相似性可考虑灰色关联。按任务选取，不默认叠加全部方法。

## 当前题目的验收

- 在公式和实现中对齐成本型、效益型和区间型指标的处理，核对零方差、全零、缺失与极端值；不让除零、重复指标或隐含变换改变权重含义。
- AHP 检查正互反矩阵及一致性。采用 CR 时说明随机一致性指标来源和阈值依据；常用 0.10 是约定，不是跨问题定理。判断冲突需回到依据，不为过线而机械修改。
- TOPSIS 独立复算标准化、加权、理想点、距离和贴近度；无差异或距离分母为零时报告不可区分，不强造排名。
- 对合理权重/口径变化检查排序及推荐是否改变；范围来自数据、题意或用户偏好，不固定扰动百分比。

DEA 的有效性相对当前样本、投入产出和规模报酬假设成立；灰色关联度是所用度量下的接近程度。主观权重、等级界限和推荐偏好缺失时需要用户确认。本文件提供方法参考，不附带已验收的评价求解器。
