# 绘图工具

通用绘图只用 **Matplotlib + Seaborn**。Seaborn 负责常见统计图，Matplotlib 负责布局、标注与示意图；不要求 R、Origin、Inkscape 或其他绘图软件。

## 先决定读者要看懂什么

一张关键图应让读者看出具体关系，例如“策略何时变化”“收益来自哪里”“在哪些条件下失效”。可以先试两种差异明显的布局；简单图直接画。不以图型新奇或多面板数量代替信息价值。

| 想解释的问题 | 可用设计起点 |
|---|---|
| 外部条件如何影响决策 | 共享时间轴的条件、决策、状态图；标出真实切换事件 |
| 小幅提升是否值得 | 改善量与计算代价并列，同时保留基线量级 |
| 效果在哪些情形不稳定 | 场景散点、区间或失效区域；平均值旁保留分布 |
| 模型里的量如何关联 | 明确对象、箭头含义、计量位置与损耗的机制图 |

布局服从内容。主结论可以占较大面板，其余面板补机制或边界；直接在关键点附近解释，减少读者来回查图例。颜色用于区分对象和强调证据，线型、形状或文字补足区分。配色、字体、标题和比例均可自主调整。

## 可直接用的代码

本 Skill 的 [figure_tools.py](../scripts/figure_tools.py) 提供中文字体选择、厘米尺寸、局部样式、关键点标注和矢量导出。将其复制到赛题项目的 utils 目录，与项目代码一起保存，再调用；无需依赖本机绝对路径。

`paper_style` 提供可调整的局部样式，接受 `font`、`size`、`colors` 和 Matplotlib 样式参数；`cm_size` 按最终页面尺寸设画布；`panel_title` 和 `note` 添加面板标题与数据点标注。读取当前赛题的真实结果，自主编写绘图代码。

`export_figure` 默认输出 PDF、可编辑文字的 SVG 和 300 DPI PNG；可通过 `formats` 只保留需要的格式。它检查缺字与画布外文字，默认拒绝覆盖同名图。

## 交付前看实际图片

打开导出的图，并放到论文最终宽度下查看：中文、公式、重叠、线条区分和字号是否清楚，重要发现能否一眼定位。程序检查不理解科学含义，也不能发现所有重叠。手工改动位置不能改变数据点、柱长或数值含义；正式图必须能从真实结果重生成。
