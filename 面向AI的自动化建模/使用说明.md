# Mathorcup自动化建模

把整个文件夹发给队友，保留隐藏的 `.agents` 和 `.vscode`。内容是跨题目、跨领域的数学建模通用 Skill；文件夹保留原名。运行不依赖旧 Skill 或 GitHub 仓库。

## 第一次用

首次配置环境，把整个文件夹交给能读写文件、运行终端的 AI，发送下面这句话：

> 请读取 `Agent环境配置指南.md` 并直接完成本机竞赛环境配置：复用已有环境，只安装必要缺项，合并项目设置，实际运行计算、绘图和 LaTeX 验收。不要只给安装建议，不覆盖其他项目；完成后告诉我哪些已通过、哪些需要我操作。

执行细节见 [Agent 环境配置指南](Agent环境配置指南.md)。已有可用环境，或当前只需阅读、改写文字时，可以直接使用 Skill。两页《队友竞赛环境手册.pdf》保留为人工操作速查。

可以直接发给 AI：

> 读取本文件夹的 `.agents/skills/mathorcup-modeling/SKILL.md`，使用数学建模通用 Skill 处理我的任务。先验收基线，再按问题和真实证据改进；复用现有环境，只加载当前需要的参考。所有产物写入我指定的项目目录。

局部改稿直接指定段落、章节或图表，只处理任务涉及的内容。论文以明确判断和主要证据为主线；关键核验实际完成，常规通过项简述，影响推荐的限制在对应结论旁交代。

## AI 如何协作

保留建模手、编程手、写作手和评委四种职能：模型先建立可信基线，计算落实真实结果，写作从早期提炼观点并反馈证据需求，评委独立审查关键疑点。主 Agent 负责统筹、整合和最终核验。简单任务合并承担，需要时按当前平台能力和协作规则委派；不要求四个代理常驻，也不增加固定审批流程。没有独立代理时如实采用主 Agent 自查。

## 绘图

只用 Matplotlib + Seaborn。AI 需要出图时读取 [绘图工具](.agents/skills/mathorcup-modeling/references/figures.md)，使用当前赛题的真实数据，按内容设计图型、标注和布局。包内辅助函数处理中文字体及 PNG、PDF、SVG 导出。

## 基线与方法参考

旧版方法已整理到 [基线模型库](.agents/skills/mathorcup-modeling/references/baselines.md)：六类方法指南按需读取，附均值、OLS、朴素预测、移动均值和容量设施选址五个可运行基线。代码使用已有 NumPy/SciPy，原模板中的数值与接口问题已修正。每道题仍先核验适用条件、实现和真实输入上的结果，再正式比较改进。

## 队内交接

论文统一交付 `.tex`、实际用到的 `.bib`、图表素材及编译后的 PDF。每个人都能编辑、编译和预览，不生成 Word 文稿。

用 VS Code 打开完整文件夹，安装 LaTeX Workshop 扩展。包内 `.vscode` 已配置 XeLaTeX 两遍编译和内置 PDF 预览：打开主 `.tex`，按 `Ctrl+Alt+B` 编译，按 `Ctrl+Alt+V` 预览。新赛题另建目录时，将 `.vscode` 一起复制过去；已有设置请让 AI 合并，避免覆盖。

保留代码、参数、运行命令与论文源文件，不复制 `.venv`。新电脑基础库清单在 `requirements.txt`；依赖安装只补缺项，不顺带升级已有环境。

需要登记或核对文件是否变化时，使用包内 `scripts/evidence.py` 的 `snapshot` / `verify`。自检脚本和用法详见 [交付与环境](.agents/skills/mathorcup-modeling/references/delivery.md)。

用于竞赛时，当届赛事的格式和 AI 使用要求以官方材料为准。
