# 分类

用于有真实类别标签的预测。先确认标签含义、预测时点、样本单位与关键类别；连续目标或无标签分群需用其他结构。

## 基线与候选

先保留多数类或类别先验的简单对照，再建立可解释的逻辑回归。随机森林、SVM、KNN 按数据结构进入候选，不默认全部运行。缩放对逻辑回归、SVM、KNN 通常有帮助；随机森林一般不依赖统一特征尺度。

## 当前题目的验收

- 划分数据后再学习缺失填补、编码、缩放和采样规则；有时间或主体依赖时保留对应隔离，不能只按类别随机分层。
- 独立复算混淆矩阵与重点类别的 Precision/Recall/F1，类别不平衡时避免仅用 Accuracy 比较。
- ROC-AUC 使用与正类一致的概率或连续决策分数；不能用硬标签替代完整排序信息。多分类须说明平均方式与类别顺序。依据见 [scikit-learn 文档](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_auc_score.html)。
- 阈值和参数在训练/验证阶段确定；测试集不参与调参。更换阈值后重新评估漏报、误报和题目规定的代价。

只有标签、代价或处置偏好缺失且会改变答案时请求人工选择。变量重要性用于解释预测关系，不能自动当成因果证据。本文件提供方法参考，不附带已验收的分类求解器。
