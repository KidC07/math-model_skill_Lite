# 聚类

用于无标签的结构发现。先明确对象、特征的距离含义与分群用途；编号和名称编码不自然具有数值距离。异常样本可能是真实特殊对象，处理方式需有依据。

## 基线与候选

对经过合理缩放、群体较紧凑的数据可先用 K-means；层次结构或中小样本可考虑层次聚类；不规则形状与噪声识别可考虑 DBSCAN。算法选择不由模型熟悉程度决定。

## 当前题目的验收

- 同时查看目标函数、可计算时的轮廓系数、群体规模及原始量纲画像；二维投影不能单独证明分群质量。
- K-means 记录初始化方式与重复运行情况，检查局部解及分群稳定性。协方差特征值比表示方差尺度比，几何轴长比是其平方根；奇异协方差需另行处理，不设置普适“球形”阈值。
- Ward 联结建立在欧氏几何上；DBSCAN 联合检查距离尺度、邻域参数、群数和噪声比例，`-1` 不能自动解释成错误数据。
- 对会影响结论的缩放、特征或群数选择做针对性对照，解释哪些对象或群体发生变化。

簇编号不表示高低等级，分群不等于真实类别。多个方案都合理时，展示差异及其对用途的影响，缺失的业务偏好由用户决定。本文件提供方法参考，不附带已验收的聚类求解器。
