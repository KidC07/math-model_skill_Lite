# 机理与动态系统

从有依据的过程关系出发，定义状态、存量、流量、时间尺度与空间边界。守恒、生成、损失、转移和反馈逐项进入方程；观测关系与状态方程分别说明。

## 基线与候选

先用可解释的平衡关系、简化差分或可核验动态模型形成起点。连续演化再按需要用 ODE/PDE，明确的局部相互作用可用元胞自动机；不靠模型名称替代机制依据。

## 当前题目的验收

- 核对每项量纲、初始/边界条件、参数来源及合理范围；连续变化率与单期变化量之间需保留时间步长。
- 检查非负性、守恒与比例范围；通过解析情形、平衡解或独立数值方法核对关键行为。
- 数值方法匹配刚性、尺度和稳定性要求。按项目精度设定容差，比较步长/容差改变后关键指标的变化，不能仅凭“曲线平滑”接受结果。
- 参数拟合与检验使用相应独立信息；元胞自动机明确同步或异步更新机制，同步机制须避免原地更新引入顺序效应。

只有被主张为重要的参数、初值或机制才安排针对性辨识和敏感性核验。没有来源的参数只能作为明确的假设或待估量；一次模拟不能代替真实观测。本文件提供方法参考，不附带已验收的机理求解器。
