# 回归与时序预测

用于估计连续目标。先区分同一观察条件下的回归与面向未来的预测，写清目标、单位、预测时点、预测期和当时可用特征。

## 基线与候选

回归以训练均值和含截距 OLS 建立对照；共线性、过拟合或参数不稳定时再考虑 Ridge/Lasso。时序先比较朴素法、尾部移动均值；周期有数据依据时增加季节朴素法。可运行入口见 [基线库](../baselines.md)。

ARIMA/SARIMA、GM(1,1) 或神经网络应由数据结构和验证收益支持。少量正数并不足以证明灰色模型适用；ADF、残差检验或训练拟合优度也不能单独证明预测能力。

## 当前题目的验收

- 数据划分匹配实际使用：时间前推、主体隔离或其他明确的独立验证口径；预处理和特征选择只在训练部分拟合。
- 固定起点预测与滚动一步预测分别报告。后者只能在真实观测到达后更新历史，不能拿它的误差冒充整段提前预测的误差。
- 用同一目标、预测期和可用信息重算 MAE/RMSE；常数目标下 R² 未定义。目标含零、近零或跨正负时，百分比误差需另行判断适用性。
- 检查失效时段、外推范围与所声称的稳定性。给出预测区间时说明构造方法，并用对应验证数据检查覆盖情况。

未来协变量、异常事件处理或误差代价存在会改变答案的歧义时，由用户补充依据；字段名和模型效果不能代替这些选择。回归关系不自动构成因果关系。
